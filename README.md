## 📝 What I Write About

Over on [simonpainter.com](https://www.simonpainter.com) I write deep-dive technical articles aimed at network engineers navigating the transition into cloud. Recent topics include:

![BGP](https://img.shields.io/badge/-BGP-informational?style=flat-square)
![DNS](https://img.shields.io/badge/-DNS-informational?style=flat-square)
![Azure Networking](https://img.shields.io/badge/-Azure%20Networking-0078D4?style=flat-square&logo=microsoftazure&logoColor=white)
![AWS Networking](https://img.shields.io/badge/-AWS%20Networking-FF9900?style=flat-square&logo=amazonaws&logoColor=white)
![Zero Trust](https://img.shields.io/badge/-Zero%20Trust-brightgreen?style=flat-square)

- **Azure networking** — Virtual Network Routing Appliance, hub-and-spoke patterns, and AZ-700 prep

- **AI & automation** — BGP Route Server MCP, reducing meeting overhead with intent capture
